# 🚀 Developer Portfolio

A sleek, modern, and fully responsive developer portfolio built using pure HTML5 and CSS3. Features a clean user interface, custom theme switcher, and a showcase of key projects and technical skills.

---

## 🔗 Live Demo

👉 **[View Live Site](https://panwarshalini.github.io/developer-portfolio/)**

---

## ✨ Features

* **Pure HTML & CSS:** Built completely without JavaScript frameworks or external libraries.
* **Responsive Design:** Seamlessly adapts to desktop, tablet, and mobile screens using CSS Flexbox and Grid.
* **Theme Switcher:** Toggle between Dark and Light mode using pure CSS state management.
* **Interactive UI:** Smooth CSS scrolling, clean typography, and minimalist layout.
* **Contact Section:** Direct links to email, LinkedIn, and social profiles.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic markup and page structure
* **CSS3** – Custom styling, animations, Flexbox/Grid layouts, and CSS variables

## ⚡ Quick Start

To view or run this project locally on your machine:

1. **Clone the repository:**
```bash
git clone https://github.com/panwarshalini/developer-portfolio.git
```

2. **Navigate into the directory:**
```bash
cd developer-portfolio
```

3. **Open in browser:**
Double-click index.html or open it directly in any modern web browser.
